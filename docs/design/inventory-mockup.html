Warehouse revamp: item icons

Every item gets a 48×48 placeholder icon drawn in code from a small descriptor (shape, tint, badge). No image files, no outside art. Human-made art replaces them later, one icon key per item.

Placeholders. These icons are for the game screen during Early Access. The Steam page, capsule art and trailer need human-made art (see the store-page plan). Any icon can be swapped for a drawn one by its key without touching game code.

Icon sheet

All 23 items, 9 bulk stocks and tanbark (cash, not an item). "Live" items are in the game today; "Planned" come with the species and Sawmill slices; "Fishing" are stubs for the Fishing camp.

Icon rules

One frame, four rarities, five states. Rarity is shown three ways (frame color, frame weight, pips on the top edge) and always named in text, so it never relies on color.

Sizes

24 px for toasts and order cards, 48 px in the grid, 96 px in the detail pane.

Palette

One ink outline (2 px, round joins) and flat fills from a coast palette. Icons look the same in both themes, as drawn art would; only the tile behind them changes.

Warehouse screen

A mid-game sample (Logging outpost 4, Sawmill open). Tap any tile. Selling and locking work in this mockup. The sidebar and top bar are stand-ins for the parallel UI rework.
